# Changelog - Haerriz_GoogleShoppingFeed

All notable changes to the `Haerriz_GoogleShoppingFeed` Magento 2 module are documented here.

## [2.5.0] - 2026-07-30

### Added
- **Preset Mapping Auto-Fallback**: Updated `RowBuilder` to automatically resolve channel-specific default attribute mappings when profile mapping configuration is empty.
- **Google Rich Results & SEO Microdata**: Added `StructuredData` block and layout component rendering Schema.org JSON-LD microdata (`@context: https://schema.org`, `@type: Product`, offer price, currency, availability) on product pages for enhanced Google Search indexing.
- **All 11 Feed Channels Batch Exporter**: Verified feed generation across Google, Meta, Instagram, Snapchat, TikTok, Pinterest, Microsoft, Amazon, eBay, Rakuten, and OpenAI channels.
